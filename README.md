 Humidity Sensor System

A laboratory project focused on the design, measurement, and analysis of a humidity sensor system.

## Project Overview

This project investigates the operation of a capacitive humidity sensor and the associated measurement and data-acquisition system. The measured data were processed and analysed using Python.

## Technologies & Tools

- Capacitive Humidity Sensor
- Sensor Measurement & Data Acquisition
- Python
- Data Analysis
- Laboratory Instrumentation
